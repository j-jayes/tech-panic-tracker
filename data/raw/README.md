# data/raw/

Source full texts live here during processing but are **git-ignored** (only this README and .gitkeep are tracked).

Policy (constitution, Open-Science Constraints): copyrighted full texts are never distributed with this repository. Each source's `full_text_location` in `sources.csv` points either to a file here (open-licence/public-domain texts may be committed by exception, noted per file) or to an external locator (`archive_url` permalink + `quote_locator`). Short verbatim quotes in the dataset rely on fair use/fair dealing.
